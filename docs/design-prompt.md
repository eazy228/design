# Промпт для редизайна сайта криптообменника SolidChange

> Готовый промпт для подачи в нейросеть-дизайнер (Midjourney / Figma AI / v0 / Lovable / Galileo / Stitch / любой LLM, генерирующий UI) или для дизайнера-человека. Заточен под редизайн действующего сайта **solidchange.online**.
>
> Документ состоит из четырёх частей: (0) аудит текущего сайта, (1) короткий промпт для генераторов с лимитом токенов, (2) расширенный бриф, (3) антипромпт.

---

## 0. Аудит текущего solidchange.online (что есть сейчас и почему это надо менять)

Сайт построен на готовом PHP-шаблоне **Coinectra / Solidus** (Changelly-clone script). Это сразу видно и подрывает доверие, что для обменника критично.

### 0.1. Проблемы брендинга и доверия

| Проблема | Что сейчас | Почему плохо |
|---|---|---|
| Расхождение названий | Логотип = **Coinectra**, `<title>` = **Solidus**, домен = **solidchange.online** | Пользователь не понимает, как называется сервис. Сразу читается как «купили шаблон, не доделали». |
| Плейсхолдер-контент | Контакты: `demo@example.com`, `+45345847431324`, «Бейкер-стрит, 22, Лондон» | Это адрес Шерлока Холмса и явно бутафорный email/телефон. Уровень доверия — ноль. |
| Фейковые отзывы | «Mitsubishi из Токио», «Алекс Круз» повторяется 3 раза (Дублин/Сидней/неизвестно), стоковые аватары | Любой пользователь распознает шаблонные отзывы. Лучше показывать настоящий рейтинг с BestChange/Trustpilot. |
| Внешние ссылки на чужие домены | Кнопки «Начать» / «Get in app» / «Подробнее» ведут на `bugfinder.net` и `youtube.com/@bugfinder3340` | Уход с домена обменника на сторонний сайт = классический сигнал скама. Должны вести во внутренний обмен. |
| Языковая каша | RU-интерфейс, но баннер «Exchange crypto for a 0% service fee in the app! Get in app», подпись над формой «Hottest rates for USDT/BTC, USDT/ETH swaps» | Микс языков в UI — признак непрофессионализма. |
| Нерабочие вкладки | В форме обмена 3 таба (Обмен / Покупка / Продажа), но Покупка и Продажа не работают | Лучше убрать пустые вкладки, чем показывать «заглушки». |
| Авторские права | «Copyright ©2026 Solidus» | Год в будущем + имя шаблона вместо реального бренда. |

### 0.2. Проблемы визуального языка

- **Палитра «крипто-казино»**: насыщенный фиолетовый → розовый/синий градиент на CTA, ярко-сиреневое слово SOLIDUS, золотистая 3D-монета Bitcoin парит в hero. Это ровно то, чего вы хотите избежать.
- **3D-иллюстрации**: парящая золотая монета BTC, орбита с биткоином, абстрактные фиолетовые декоры — типичный «web3 glow».
- **Стоковые фото**: бизнесмен с iPad на фоне графика (about-секция) — клише, разрушает доверие.
- **Дешёвые декоративные элементы**: звёздочки, точки, «corner-half», «border-round» из набора шаблона — захламляют макет.
- **Контраст и иерархия**: H1 «Обменивайте Любую Криптовалюту Быстро И Безопасно» с каждым словом с заглавной — выглядит как машинный заголовок, не как редактура.
- **Тени и блики**: тяжёлые drop-shadow под кнопками и формой, фиолетовое свечение — тот самый «эффект казино».

### 0.3. Структурные проблемы

Текущая последовательность секций главной:

1. Hero (форма обмена + 3D-монета)
2. About (CoinEctra — кто мы) — стоковое фото
3. Преимущества (4 пункта)
4. Как проходит работа (4 шага)
5. Почему выбирают CoinEctra (4 пункта) — **дублирует п. 3**
6. FAQ
7. Отзывы (фейк)
8. Блог
9. Newsletter
10. Footer

**Замечания**:
- Пп. 3 и 5 — фактически одна и та же секция «преимущества», просто с разными формулировками. Объединить.
- Нет блока **онлайн-курсов** валют (есть в вашем брифе).
- Нет блока **популярные криптовалюты** (есть в вашем брифе).
- Нет блока **безопасность и AML/KYC** (есть в вашем брифе).
- Нет блока **резервы и индикаторы доверия** (главный USP обменника — отсутствует).
- About и Blog на главной — отвлекают от обмена. About вынести на отдельную страницу, Blog — оставить только превью из 3 карточек либо убрать вовсе.
- Newsletter сейчас занимает много места, но не критичен — оставить как тонкую полосу в footer-зоне.

### 0.4. Что из текущего сайта стоит сохранить

Не всё плохо, есть рабочие основы:

- **Переключатель темы** (sun/moon, light/dark) — полезно, оставить, но перерисовать иконку.
- **Языковой переключатель** (RU/EN) с флагом — оставить, но убрать «РФ-флаг = русский язык» (есть пользователи в Беларуси/Казахстане/Украине, у кого этот флаг вызывает вопросы — лучше глобус + текст «RU/EN»).
- **Структура «отправляете → ⇅ → получаете»** в форме — корректная, оставить.
- **Sticky-навигация** сверху — оставить, перерисовать.
- **Раздел FAQ как accordion** — оставить.
- **Tracking-страница** (`/tracking`) — отличная функция для прозрачности, вынести ссылку на видное место в навигацию.

### 0.5. Цель редизайна (одной фразой)

Превратить шаблонный «Changelly-clone» с фиолетовым казино-стилем в **сдержанный, технологичный обменник в стиле private banking**, в котором каждый элемент работает на доверие, а пользователь без скролла видит сумму, курс, комиссии и итог.

## 2. Расширенный бриф (для дизайнера / детальной генерации)

### 2.1. Позиционирование и брендинг

**Имя бренда**: SolidChange (по домену solidchange.online). Везде убрать «Coinectra» и «Solidus». Допустимое написание: `SolidChange` (Pascal-case), допустимое сокращение в логотипе/favicon: `SC`. Лого — словесная метка `SolidChange` в моно-линейном sans-serif + опционально лаконичный знак (например, две диагональные стрелки `⇄` в круге 1px stroke, без градиентов и свечений).

Сайт — обменник криптовалют, рассчитанный на пользователя, который **уже видел десяток «крипто-казино» и устал от них**. Визуальный язык — на пересечении:
- private banking (Revolut Metal, N26 Black, Wise Business),
- инфраструктурный fintech (Stripe, Mercury, Ramp, Stripe Atlas),
- институциональный crypto (Fireblocks, Anchorage, Kraken Pro, Coinbase Prime).

Эмоция, которую должен испытать пользователь за первые 3 секунды: «здесь не обманут, тут взрослые люди, всё работает».

**Обязательно к замене на сайте на этапе редизайна**:
- логотип, `<title>`, favicon, `og:title`, footer copyright — везде `SolidChange`;
- контактные данные `demo@example.com`, `+45...`, «Бейкер-стрит, 22» — заменить на реальные;
- все CTA-ссылки на `bugfinder.net` и `youtube.com/@bugfinder3340` — на внутренние страницы (`/exchange`, `/about`, `/blog`);
- английские микро-надписи в RU-интерфейсе — перевести;
- демо-отзывы и стоковые аватары — убрать, заменить на агрегированный рейтинг с BestChange/Trustpilot.

### 2.2. Что должно считываться мгновенно

В swap-карточке без скролла и без клика пользователь видит:
1. **Что отдаёт** — сумма, актив, сеть, баланс/мин-макс.
2. **Что получает** — сумма (рассчитанная автоматически), актив, сеть.
3. **Курс** — `1 X = Y` плюс отметка «обновлено N сек назад» и индикатор фиксации курса (если есть).
4. **Комиссии** — раздельно: сеть-отправитель, сеть-получатель, сервис; и **итог одной строкой**.
5. **Итоговая сумма к получению** — отдельный, визуально приоритетный блок.
6. **Кнопка действия** — одна, контрастная, с явным глаголом («Обменять»).
7. **Полоса доверия** — резервы, лицензия/юрисдикция, время выполнения, поддержка 24/7.

Всё остальное (история, реферал, FAQ) — ниже по скроллу, не отвлекает.

### 2.4. Типографика

- **UI**: Inter / Geist / Söhne / IBM Plex Sans. Один шрифт по всему интерфейсу.
- **Цифры и суммы**: обязательно `font-variant-numeric: tabular-nums`. Цифры одной ширины — обмен «не дёргается» при пересчёте.
- **Заголовки**: вес 500–600, никогда не 300 и не 100 (тонкие шрифты считываются как «дешёвый дизайн»).
- **Размеры (desktop)**:
  - H1 — 48–56 px, line-height 1.1
  - H2 — 32–36
  - H3 — 22–24
  - Body — 15–16, line-height 1.5
  - Caption / labels — 12–13, uppercase, letter-spacing 0.04em
  - Amount display — 36–48, weight 500, tabular-nums
- Никаких декоративных шрифтов, никаких засечек в логотипе криптообменника (засечки → банк → ассоциация с «олдскульно», что мы не хотим в техно-стиле).

### 2.5. Сетка и пространство

- 12-колонный grid, gutter 24 px, max-width 1200–1280 px.
- Базовая шкала отступов: 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 px.
- Радиусы: `8 px` для инпутов, `16 px` для карточек, `999 px` для пилюль-чипов. Не смешивать радиусы в одном блоке.
- Тени минимальны: одна тонкая (`0 1px 0 rgba(255,255,255,0.04) inset`) на карточках. Никаких больших размытых синих/фиолетовых glow.

### 2.6. Иконки и иллюстрации

- Иконки: **моно-линейные**, обводка 1.5 px, набор уровня Phosphor / Lucide / Radix.
- Логотипы криптовалют: официальные SVG, монохромные на фоне карточек (цвет включается только при выборе/hover).
- **Запрещено**: 3D-монеты с глянцем, изометрические композиции, эмодзи в продакшен-копирайте, мультяшные персонажи, «ракета», «луна», «алмазные руки».
- Допустимо: тонкие абстрактные паттерны (сетка, гильош) в hero — очень низкой контрастности.

**Селектор актива**: модалка с поиском, списком, фильтром по сети, индикацией резерва («в наличии: 12.4 BTC»). Сразу видно, если резерва не хватает.

**Селектор сети**: чипы, не дропдаун. Активная сеть подсвечена accent-цветом, неактивные — нейтральные. Подпись: «Комиссия сети ~$0.40, время ~2 мин».

**Status tracker** (после старта обмена): 4 шага — «Оплата получена → Подтверждено в сети → Конвертация → Отправлено». Горизонтальная полоса с прогрессом, текущим шагом и таймером.

**Trust badges**: ряд под swap'ом — резерв в реальном времени, статус AML, ссылка на on-chain верификацию (Etherscan/Tronscan адресов холодных кошельков).

### 2.8. UX-флоу обмена (happy path, без логина)

1. **Лендинг** → swap-карточка в hero, открыта по умолчанию.
2. Пользователь вводит сумму → курс/комиссии/итог пересчитываются inline без перезагрузки.
3. Нажимает «Обменять» → одностраничный wizard:
   - Шаг 1: email (опционально) + промокод/реферал.
   - Шаг 2: адрес получения (с валидацией формата сети и чек-суммы; явное предупреждение, если адрес похож на адрес другой сети).
   - Шаг 3: подтверждение условий обмена — фиксация курса на N минут, повторно показаны все цифры.
   - Шаг 4: реквизиты для оплаты — QR + адрес + memo (если требуется) + точная сумма с указанием «отправьте ровно столько».
4. **Статус-страница** — live-обновление через WS/polling, без перезагрузки. Показывает on-chain хэши обеих транзакций.
5. **Завершение** — хэш исходящей транзакции, ссылка на explorer, кнопки «Новый обмен» и «Сохранить квитанцию (PDF)».

Принцип: **на каждом шаге пользователь видит, сколько он получит в итоге**. Цифра не должна «прятаться».

#### 1. Hero-блок с формой обмена
- Высота: ~92 vh на desktop, full-width.
- Фон: градиент `#1A0F14 → #3A1F2B` + еле заметный гильош/сеточный паттерн с opacity 4%.
- Слева (5 колонок): H1 «Обмен криптовалют без скрытых комиссий», подзаголовок одной строкой, 3 буллета с моно-иконками («Резервы on-chain», «AML-проверка Chainalysis», «Поддержка 24/7»).
- Справа (6 колонок): swap-карточка (см. п. 2.7) — это **главный элемент страницы**, она должна быть выше «линии сгиба».
- Сверху над hero — sticky-навигация: лого + 4 пункта меню + кнопка «Войти» (ghost) + язык (RU/EN).
- На mobile: swap-карточка под заголовком, заголовок сокращён до 2 строк.

#### 2. Онлайн курсы валют
- Подзаголовок секции: «Курсы в реальном времени» + значок «обновлено N сек назад».
- Формат: горизонтальная **ticker-лента** (бесконечный auto-scroll очень медленно, 30+ сек на проход; на hover пауза) + ниже компактная таблица топ-12 пар.
- В таблице колонки: пара (иконка + тикер), цена, изменение 24ч (с muted-green/muted-red и стрелкой ↑/↓), мини-спарклайн 24ч (1px stroke, без заливки), кнопка-чип «Обменять» — переносит сумму в hero-форму и скроллит наверх.
- Спарклайн строго монохром (text-secondary), единственный акцент — цвет изменения.
- Никаких блестящих свечных графиков как у Binance — это не трейдинг, это обменник.

#### 3. Популярные криптовалюты
- Grid 4×2 (desktop) / 2×4 (mobile) карточек.
- Каждая карточка: моно-логотип монеты, тикер, полное имя, текущая цена USD, изменение 24ч, кнопка «Купить» (secondary).
- Hover-состояние: тонкая обводка accent-цветом, без масштабирования и без glow.
- Радиус 16 px, фон `#150C10`, border `rgba(255,255,255,0.06)`.
- Клик по карточке = открыть hero-форму с предзаполненным «получаете = эта монета».

#### 4. Блок безопасности и AML/KYC
- Двухколоночный layout: слева крупный заголовок «Безопасность как у банка, скорость как у крипты», справа абзац-обоснование.
- Ниже — 4 карточки с моно-иконками (щит/документ/ключ/глаз):
  - **AML-проверка** — Chainalysis / Elliptic, объяснение в одной фразе.
  - **KYC при необходимости** — пороги в цифрах, прозрачно, без «по требованию модератора».
  - **Холодное хранение** — % средств в холодных кошельках, ссылка на on-chain доказательство.
  - **Двухфакторная аутентификация** — обязательна для аккаунтов от X объёма.
- Внизу секции — лого партнёров (Chainalysis, Elliptic, Sumsub и т.п.) в монохроме, opacity 60%, в hover до 100%.

#### 5. Как работает сервис
- Горизонтальная схема из **4 шагов** с тонкими соединительными линиями между ними (1px dashed, не анимировано):
  1. Выбираете пару и сумму
  2. Указываете адрес получения
  3. Отправляете криптовалюту по реквизитам
  4. Получаете обмен на свой кошелёк
- Каждый шаг: номер в круге (1px border, accent-цвет), иконка моно-линейная, заголовок 1 строка, описание 2 строки.
- Под схемой — строка «Среднее время операции: ~7 минут» с иконкой часов.
- На mobile — вертикальный stepper с вертикальной линией слева.

#### 6. Преимущества платформы
- Bento-grid 3×2 (6 карточек разного размера для визуального ритма), без оверлеев и градиентов внутри карточек.
- Преимущества (формулировать в цифрах и фактах, не в эмоциях):
  - «**Комиссия от 0.5%**» — крупно цифра + поясняющий текст.
  - «**Более 200 пар**» — с миниатюрой grid'а иконок.
  - «**Резервы в открытом доступе**» — с мини-графиком резерва.
  - «**Среднее время — 7 минут**» — с гистограммой по часам.
  - «**Поддержка 24/7 на 5 языках**» — с компактным аватаром оператора (опционально, без stock-фото).
  - «**Лицензия и юрисдикция**» — герб/печать в виде моно-иконки + страна.
- Запрещено в этой секции: stock-фото улыбающихся людей в офисе, рукопожатия, графики «вверх до луны».

#### 7. Резервы и индикаторы доверия
- Заголовок: «Резервы 1:1, проверяйте сами».
- Таблица холодных кошельков (8–15 строк): актив, сеть, текущий резерв, эквивалент USD, ссылка «Посмотреть on-chain» (открывает Etherscan/Tronscan/Mempool в новой вкладке).
- Над таблицей — строка-сумма «Общий резерв ≈ $X.XX M» с таймстампом обновления.
- Под таблицей — три KPI-плитки:
  - «**Объём за 30 дней**» — крупная цифра в шампань-акценте.
  - «**Завершено обменов**» — счётчик с tabular-nums (без анимации одометра!).
  - «**Uptime сервиса 99.9X%**» — ссылка на публичную статус-страницу.
- Принцип: всё, что показано, проверяемо on-chain. Никаких «доверьтесь нам».

### 2.10. Состояния и edge-cases (обязательно нарисовать)

- Скелетоны при загрузке курса.
- Состояние «курс изменился больше чем на X%» — мягкий warning, не блокирующий, с кнопкой «Принять новый курс».
- Состояние «резерва не хватает» — disabled CTA + понятная подсказка «Доступно к обмену: 0.8 BTC».
- Невалидный адрес — inline-ошибка под полем, не модалка.
- Ошибка сети при сабмите — toast в углу, не закрывающий swap-карточку.
- Empty state истории обменов — без иллюстрации, просто текст и кнопка.

### 2.11. Анимации (whitelist)

Разрешены **только**:
- Tabular-roll цифр при пересчёте (200–250 ms, ease-out).
- Появление подсказок и тостов (fade + 4 px translate, 150 ms).
- Состояние focus у инпутов (border-color transition, 100 ms).
- Прогресс-бар статуса обмена (линейная анимация, без блёсток).
- Success checkmark по завершении (SVG draw, 400 ms).

Запрещены: parallax, плавающие монеты, частицы, неоновые свечения, hover-эффекты на 3D-карточках, анимированные градиенты в фоне, lottie-иллюстрации длиннее 1 секунды.

### 2.12. Адаптив

- Mobile-first для swap-карточки: она должна работать одной рукой, ввод суммы — главный приоритет.
- На mobile selector актива открывается bottom-sheet'ом, не модалкой по центру.
- Минимальная hit-area у элементов — 44×44 px.
- Tab order по форме обмена логичный сверху вниз, swap-кнопка (⇅) доступна с клавиатуры.

### 2.13. Доступность

- Контраст текста к фону ≥ 4.5:1 для body, ≥ 3:1 для крупного.
- Состояние focus visible на всех интерактивных элементах (1.5 px outline accent-цветом, offset 2 px).
- Все иконки имеют `aria-label` или сопровождаются текстом.
- Цвет не единственный носитель смысла (success/danger дублируются иконкой).

### 2.14. Tone of voice (UI copy)

- Короткие, фактические формулировки. Активный залог.
- Никаких «🚀», «to the moon», «hodl», «degen».
- Цифры всегда с разделителями тысяч и фиксированным числом знаков после запятой по активу.
- Ошибки — без вины пользователя («Адрес не похож на TRC-20. Проверьте сеть.»), не «Вы ввели неправильно».

### 2.15. Deliverables, которые ожидаются от дизайнера / генератора

1. Desktop (1440 px): главная страница целиком — все 10 блоков из п. 2.9, плюс sticky-навигация и footer.
2. Mobile (390 px): главная страница целиком, все 10 блоков в адаптивной вёрстке.
3. Hero-блок отдельно: desktop + mobile, со всеми состояниями swap-карточки (default / loading / rate-changed / insufficient-reserve / invalid-address / success).
4. Status-страница обмена (desktop + mobile).
5. Wizard обмена (4 шага) — desktop + mobile.
6. Компонентная библиотека: button (primary/secondary/ghost), input, select, chip, toast, modal, table-row, status-step, accordion-item, ticker-cell, kpi-tile, review-card.
7. Стайлгайд: палитра (с HEX), типошкала, spacing-scale, радиусы, тени, иконки.
8. Список секций главной страницы (для разработчика): порядок, высоты, breakpoints, content placeholder'ы.
